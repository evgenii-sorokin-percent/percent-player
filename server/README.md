# Percent Player Server

Express and SEA server

## Technologies  

- **Express 5** - Web framework
- **Zod 4** - Schema validation
- **Consola 3** - Logger
- **get-port 7** - Auto-selection of free TCP ports
- **tsx 4** - Hot reload
- **Rolldown** - Bundler

## Commands

### Development

```bash
pnpm dev # Run dev server
```

### Building

```bash
pnpm build # Build
```

### Linting

```bash
pnpm lint # Lint
pnpm lint:fix # Lint with fix 
```

### Formatting

```bash
pnpm format # Format
pnpm format:check # Check formatting
```
